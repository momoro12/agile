## 📋 Шкала оценок (Фибоначчи + спец. карты)

| Карта | Значение | Интерпретация |
|-------|----------|---------------|
| `0` | 0 | Задача уже выполнена / тривиальна |
| `1–3` | Малые | Простые задачи, 1–2 дня работы |
| `5–13` | Средние | Требуют анализа и координации, 3–10 дней |
| `21–55` | Крупные | Сложные, многокомпонентные задачи |
| `89` | Глобальные | Эпик, требующий декомпозиции |
| `∞` | Бесконечность | Задача неопределённа или нереализуема в текущем виде |
| `?` | Вопрос | Нужны уточнения у владельца продукта |
| `☕` | Кофе-брейк | Предложение сделать перерыв |

> 🎯 **Правило**: Оценки выставляются анонимно, затем вскрываются одновременно. При расхождении >2 значений — обсуждение и повторное голосование.

## 🔄 Алгоритм проведения Planning Poker (кратко)

1. **Подготовка**: Владелец продукта кратко представляет пользовательскую историю, отвечает на вопросы.
2. **Оценка**: Каждый участник выбирает карту с оценкой, не показывая её другим.
3. **Вскрытие**: Все одновременно открывают карты.
4. **Обсуждение**: Если оценки расходятся более чем на 2 значения — участники с минимальной и максимальной оценкой аргументируют позицию.
5. **Повтор**: Голосование повторяется до достижения консенсуса или компромисса.
6. **Фиксация**: Итоговая оценка записывается в бэклог задачи.
